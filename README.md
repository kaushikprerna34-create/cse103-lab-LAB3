Computer Fundamentals & Career Pathways (CSE103) course at

The purpose of this practical is to understand Git,
GitHub collaboration, API interaction and Markdown documentation.


Navigate to the project:

```bash
cd cse103-lab-LAB3
```

Run the Python program:
